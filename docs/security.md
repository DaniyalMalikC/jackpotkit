# Security

Report suspected vulnerabilities privately through the repository's GitHub Security Advisory interface. Do not include secrets, customer data, or exploit details in a public issue.

JackpotKit has no payment, wallet, KYC, settlement, or licensing functionality. Applications remain responsible for authorization, eligibility, fraud controls, result persistence, regulatory obligations, and secure reward fulfilment.

See [Server-authoritative results](./server-authoritative-results.md) for the recommended result flow.
