# Roadmap

## Completed

- Phase 0: monorepo, package shells, build system, testing foundations, examples, documentation shell, CI, and Changesets.

## Planned

1. Phase 1: shared core results, rewards, lifecycle, randomness, result providers, errors, validation, and testing helpers.
2. Phase 2: Spin Wheel as the end-to-end reference game.
3. Phase 3: Scratch Card with isolated Skia rendering.
4. Phase 4: Slot Machine.
5. Phase 5: Bingo.
6. Phase 6: Dice, Coin Flip, and Lucky Box.
7. Phase 7: React web renderers.
8. Phase 8: stable-release hardening and publication readiness.

Roadmap entries are not available APIs and should not be presented as implemented until their complete definition of done passes.
