# Roadmap

## Completed

- Phase 0: monorepo, package shells, build system, testing foundations, examples, documentation shell, CI, and Changesets.
- Phase 1: shared results, rewards, lifecycle vocabulary, randomness, result providers, typed errors, validation, events, and deterministic testing helpers.
- Phase 2: Spin Wheel headless engine, React Native hook and renderer, result modes, animation, themes, accessibility, tests, playground, and documentation.

## Planned

1. Phase 3: Scratch Card with isolated Skia rendering.
2. Phase 4: Slot Machine.
3. Phase 5: Bingo.
4. Phase 6: Dice, Coin Flip, and Lucky Box.
5. Phase 7: React web renderers.
6. Phase 8: stable-release hardening and publication readiness.

Roadmap entries are not available APIs and should not be presented as implemented until their complete definition of done passes.
