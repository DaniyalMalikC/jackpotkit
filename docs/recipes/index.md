# Recipes

Each recipe uses only exported APIs, and its code samples are type-checked by the docs build.

- [Server-authoritative rewards](./server-authoritative-rewards.mdx): let your server choose and
  store valuable outcomes, end to end.
- [Seeded previews and testing](./seeded-previews-and-testing.mdx): repeatable previews and
  deterministic tests with `@jackpotkit/testing`.
- [Controlled outcomes](./controlled-outcomes.mdx): tutorials and scripted flows with `result` and
  ref methods.
- [Analytics with callbacks](./analytics.mdx): send lifecycle events to your own analytics.
- [Reduced motion](./reduced-motion.mdx): system settings, in-app settings, and platform
  differences.
- [Translating labels](./translating-labels.mdx): which text you can translate on each platform.
