The two components share their props, callbacks, ref methods, and result types. Platform
differences are presentation details: the web takes `className`, CSS `style`, and CSS easing
strings; React Native takes `StyleProp<ViewStyle>`, Reanimated easing functions, and
`accessibilityLabels`. Each game page lists them in its generated
[API reference](./spin-wheel.mdx#api-reference).

## Where the outcome comes from

Every game resolves its outcome **before** it animates. Pick one source per game:

| Mode       | Props                             | Use it for                                                      |
| ---------- | --------------------------------- | --------------------------------------------------------------- |
| Random     | none, or `randomSource`           | Casual play, demos, and seeded previews. Not tamper-proof.      |
| Controlled | `result`, or `ref.spinTo(...)`    | Tutorials, scripted flows, and outcomes your app already knows. |
| Provider   | `resultProvider`, `resultRequest` | Rewards with value: your server decides and stores the outcome. |

The animation never decides the winner. For anything valuable, follow the
[server-authoritative reward recipe](./recipes/server-authoritative-rewards.mdx).
