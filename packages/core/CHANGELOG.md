# @jackpotkit/core

## 0.1.0

### Minor Changes

- 0c7d26f: Add the Phase 1 platform-independent primitives and deterministic testing toolkit.

  Core now includes generic results and rewards, lifecycle vocabulary, typed events, injectable and seeded random sources, sync or async result providers, typed errors, and composable validation helpers. Testing adds sequence-based randomness, a call-capturing mock result provider, and deterministic factories.

- 7a29cde: Add Spin Wheel as the first end-to-end reference game.

  The release includes a pure headless engine with weighted, controlled, and server-authoritative results; exact destination math; a React Native hook and accessible Reanimated/SVG component; imperative controls; reduced motion; platform-neutral default and neon themes; deterministic wheel factories; an interactive Expo playground; and complete game documentation.
