# Changelog

The Phase 0 package shells were initially published to npm at version `0.0.0`. Package-specific changelogs are generated by Changesets for subsequent releases.

## 1.1.0 - 2026-08-28

- Fixed a native Hermes/Worklets crash when Dice, Coin Flip, or Lucky Box animations completed.
- Added selectable Dice and Coin Flip face styles across React and React Native.
- Fixed neon Coin Flip face content contrast across React and React Native.
- Added richer Slot Machine reel animation, symbol rendering, and accessibility.
- Added improved Scratch Card rendering, visuals, and accessibility, including a web canvas renderer.
- Added gift-box Lucky Box visuals and reliable native selection resets.
- Made the Expo and web galleries use equal-probability outcomes by default, while retaining an
  explicit weighted-probability demonstration in the Expo playgrounds.
- Constrained Expo game dimensions to the available nested-card width on compact screens.
- Aligned the Expo example with the current Expo SDK 57 patch versions and React Native 0.86.3.

## 1.0.0 - 2026-08-12

- Established the Phase 0 monorepo, package shells, application shells, validation, CI, and governance files.
- Corrected the public package documentation and repository metadata after the initial npm publication.
- Added manually approved npm Trusted Publishing and automated Changesets release pull requests.
- Implemented all seven React Native and React web experiences through Phase 7.
- Added the Phase 8 stable API, accessibility, dependency, privacy, migration, package-type, and
  release-readiness review gates for the stable `1.0.0` release.
